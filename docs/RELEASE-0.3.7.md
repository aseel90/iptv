# Selyro TV 0.3.7 — Server Management, Favorites & Connection Quality

## Server management
- Delete any saved server, including the last remaining server, with confirmation.
- Edit saved Xtream or M3U server details in place.
- Confirm destructive “Clear all servers” actions.
- Keep active-account state consistent after editing or deleting a server.
- Test saved-server connectivity and show a compact response-quality indicator.

## Favorites
- Add/remove Live channels directly from the channel list or grid using ☆ / ★.
- Remove Live channels directly from the Favorites screen.
- Keep the existing player Favorite action available.

## Connection quality
- Show a compact Live playback quality indicator near the top-right player information.
- Grade playback as checking, excellent, good, weak, or offline based on startup time, buffering and playback errors.
- Show detailed startup/buffering information in the Live Info panel.
- Show saved-server latency/health in Settings.

Release target: `versionCode 17`, `versionName 0.3.7-management-favorites-quality`.
